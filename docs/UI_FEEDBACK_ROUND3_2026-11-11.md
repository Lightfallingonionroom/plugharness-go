# 实机反馈第三轮（2026-11-11，用户截图 P1–P5 + APK）

> 对照：P1/P2/P5 = ChatGPT 官方设置与新对话页；P3/P4 = 本 App。
> 这一轮是**交互与视觉**，不是编译错误。逐条记，避免漏。

## 用户提的 7 个问题

### 1. 设置首页的「框」不对（P1 vs P3）

- **P1（ChatGPT）**：**所有设置项都在同一张卡片里**，行与行之间只有细分割线；
  卡片是连续的一整块，不是每项一个框。
- **P3（我们）**：只有「配色」「明暗」两项有独立圆角框，下面「更多外观」、
  「通用」各组是裸的 → 断裂、突兀。
- 结论：**要的不是「三张卡」，是「所有项统一进卡片」**。

### 2. 展开方式不对（P2 vs P3）

- **P2（ChatGPT）**：点「外观」/「强调色」是**弹出一个浮层菜单**
  （系统 / 浅色 / 深色；蓝色 / 青色 / …），**不是就地伸展开**。
- **P3（我们）**：点开后卡片在原地长高一截，色点铺在卡片里。
- 结论：改成**弹出菜单**（锚定在行右侧，深色浮层 + 勾选态），不就地展开。

### 3. 卡片的视觉样式也不像

- P1 的卡片是「一整块、行间细线、圆角只在外轮廓」；
  我们的框是「每张各自圆角 + 内边距过大 + 明暗卡展开后大片留白」。
- 结论：统一成一张 `SettingsSection` 卡片，行高一致，分割线贯穿。

### 4. 输入条两个键位置反了（P3）

- ChatGPT：左端是 **＋**（附件），右侧靠麦克风是**模型/思考**相关。
- 我们：`＋` 在左数第二个，最左是控制面板齿轮。
- 结论：**＋ 与控制面板键交换位置** —— `＋` 到最左，控制面板键到它右边。

### 5. 麦克风左边的推理强度仪表没了（P3）

- 截图里输入条右端只有麦克风，没有 `ReasoningGaugeIcon`。
- 根因待查：`Composer` 的 `footer` 条件（窗口高度 / `isChild` / `_hasEfforts`）
  或 `catalog` 为空导致不渲染。要让它稳定出现。

### 6. 控制面板点不开（确定性 bug）

- 根因已定位：`ComposerControlsKey` 里 `Pressable` **没传 `onTap`**，
  只给了 `Semantics.onTap`（无障碍语义，不响应真实指针）。
- 修法：`Pressable(onTap: open, ...)`。

### 7. 侧边栏布局（P5 vs P4）

- **P5（ChatGPT）**：
  - 顶栏：「ChatGPT」字标 + 右侧**圆形搜索按钮**
  - 功能行：图像 / 档案库 / 自订 / 专案 / 遥控器 / 探索（**无「功能」小标题**，
    行间距紧凑，每项一个线性图标）
  - 「已钉选」小标题 + 会话行
  - 「对话」小标题 + 会话列表
  - **底栏**：左下「聊天」是**蓝色实心胶囊**（带 compose 图标 + 文字），
    右下是**圆形头像**（不是齿轮）
- **P4（我们）**：
  - 有「功能」「对话」小标题，功能行间距过大
  - 「更多」行是 `… 更多 ▾`（三点图标 + 展开箭头），显脏
  - 「全部对话 ▾」独占一行，下面大片空白
  - 底栏：左下白色圆形 compose、右下齿轮
  - 空态插图与文案挤在中间，整体留白比例不对
- 结论：按 P5 重排——去掉「功能」标题；功能行紧凑；
  底栏换蓝色实心「新对话」胶囊 + 右侧圆形头像/账户键；
  空态上移，减少空白。

## 明确不改的

- **签名**：用户说「既然这么麻烦那还是保留原本签名规律得了」——
  **不要动 CI 签名配置**，继续用现状（每次构建需卸载旧包）。
  这一条要写进报告，避免后续自己又去改。
